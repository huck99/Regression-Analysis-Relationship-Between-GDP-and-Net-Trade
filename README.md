# Regression Analysis: Relationship Between GDP and Net Trade

This repository presents a regression analysis examining the relationship between Gross Domestic Product (GDP) and Net Trade. The analysis was conducted for ECO 530 as part of the MBA Business Analytics program at the University of Maine.

## 📊 Project Objective

The goal of this project is to evaluate whether Net Trade (exports minus imports) has a significant impact on GDP. By using linear regression modeling, the analysis helps in understanding the strength and direction of this economic relationship.

## 🔍 Key Analysis Areas

- Regression Model
- Scatter Plot and Line of Best Fit
- Coefficient Interpretation (Slope & Intercept)
- Statistical Significance (p-values)
